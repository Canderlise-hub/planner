Introduction to Components

Session 1
What is it?

Building blocks of electronics

Students explore the fundamental building blocks of electronics — input modules, output modules, and power sources. They learn how these components connect and work together.

Real World UseThis foundational knowledge is the basis for every project that follows. Just like learning the alphabet before reading, understanding components is the first step to building working circuits.
What we'll learn

Identify, connect, power

  • What input and output components are
  • How power modules supply energy to circuits
  • Identifying components by sight and function
